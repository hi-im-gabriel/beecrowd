# Security Policy

## Supported versions

This repository does not publish versioned releases. Security fixes are applied
to the latest revision of the `main` branch only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, especially if
it could expose beecrowd credentials, session data, or another person's private
information.

Report vulnerabilities privately through the repository's **Security** tab by
selecting **Report a vulnerability**. If private vulnerability reporting is not
available, use the contact information on [the maintainer's GitHub
profile](https://github.com/hi-im-gabriel) to request a private reporting
channel.

Include the affected file or component, steps to reproduce the issue, its
potential impact, and any suggested mitigation. Do not include real credentials
or other secrets in the report.

You can expect an acknowledgment within seven days. After the report has been
reviewed, the maintainer will share whether it is accepted and, when practical,
the expected remediation timeline.
